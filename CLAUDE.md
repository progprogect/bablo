# Правила работы над Bablo

## Главное: боевой аккаунт

Приложение работает на реальном BingX-аккаунте — каждая сделка это реальные деньги,
каждая запись в БД это реальная статистика и прогресс риск-плана. **Проверять
функциональность «вживую» нельзя**: не открывать/не закрывать сделки, не дёргать торговые
эндпоинты и админ-действия с побочными эффектами, не поднимать сервер с боевыми ключами
BingX ради проверки. Проверка изменений — только `npm test`, `npm run typecheck`, сборка и
UI на локальной сборке с застабленными ответами API. Если проверить можно только вживую —
описать проверку и оставить решение пользователю.

Полный текст правила и остальные принципы (минимальный интерфейс, дисциплина риска,
технические инварианты) — в `.cursor/rules/product-principles.mdc`. Читать перед работой.

## Источник правды

Документация в `docs/` описывает продукт и логику и обновляется вместе с кодом:

- `docs/PROJECT.md` — экраны, флоу сделки, ограничения;
- `docs/RISK_ENGINE.md` — лестница уровней, дневные лимиты;
- `docs/ARCHITECTURE.md` — стек, модули, схема БД, API, realtime;
- `docs/ROADMAP.md` — этапы и история решений.

## Команды

```bash
npm run typecheck   # tsc по серверу и клиенту
npm test            # юнит-тесты чистой логики сервера
npm run build       # сборка клиента и сервера
```
